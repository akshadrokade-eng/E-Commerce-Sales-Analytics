# E-Commerce Analytics Dashboard

An interactive Next.js dashboard for visualizing e-commerce sales data, customer analytics, and operational metrics.

## Dashboard Features

- **5 interactive pages** with real-time data visualization
- **Premium dark theme UI** with smooth animations
- **16+ chart types** including area, bar, donut, scatter, and histogram charts
- **Responsive design** for desktop and mobile devices
- **INR currency formatting** with compact notation

## Prerequisites

- Node.js 18+ (recommended: 20+)
- npm, yarn, or pnpm

## Installation

```bash
# Install dependencies
npm install
```

## Development

```bash
# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

## Production Build

```bash
# Build for production
npm run build

# Start production server
npm start
```

## Available Routes

| Route | Description |
|-------|-------------|
| `/` | Main dashboard with KPIs and overview charts |
| `/sales` | Sales analytics with revenue, category, and regional analysis |
| `/customers` | Customer analytics with revenue distribution and rankings |
| `/operations` | Operations analytics with delivery and rating metrics |
| `/insights` | Business insights with trends, correlations, and findings |

## Data Files

Dashboard data is loaded from JSON files in `public/data/`:

- `summary.json` — KPI metrics (revenue, orders, customers)
- `category.json` — Product category analytics
- `region.json` — Regional sales data
- `payment.json` — Payment method breakdown
- `yearly.json` — Year-over-year trends
- `monthly.json` — Monthly aggregates
- `customers.json` — Customer-level analytics
- `operations.json` — Delivery and rating metrics
- `relationships.json` — Correlation data

## Data Pipeline

The dashboard reads JSON files generated by the Python pipeline. To regenerate:

```bash
# From project root
python python/07_generate_dashboard_data.py
```

This writes JSON to `web/public/data/`.

## Troubleshooting

### Missing JSON files

If you see "Unable to load data" errors, the JSON files may not exist:

```bash
# Generate dashboard data
python ../python/07_generate_dashboard_data.py
```

Ensure `public/data/` contains all 9 JSON files.

### Build errors

```bash
# Clear cache and reinstall
rm -rf node_modules .next
npm install
npm run build
```

### Port already in use

```bash
# Use a different port
npm run dev -- -p 3001
```

## Using a Custom Dataset

You can upload your own e-commerce CSV dataset to replace the default data.

### Prerequisites

1. Start the Python backend API:
```bash
# From project root
cd backend
pip install fastapi uvicorn python-multipart
uvicorn app:app --host 127.0.0.1 --port 8000
```

2. Start the Next.js dashboard:
```bash
npm run dev
```

### Upload Process

1. Click the **Dataset** button in the dashboard header
2. Select a compatible `.csv` file
3. Review the preview (first 5 rows, column list)
4. Click **Process Dataset**
5. Dashboard refreshes with new data

### Required CSV Columns

Your CSV must contain these columns:
- `order_id`
- `order_date`
- `customer_id`
- `product_category`
- `region`
- `quantity`
- `unit_price`
- `discount`
- `payment_method`
- `delivery_days`
- `customer_rating`
- `revenue`

### API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/health` | GET | Health check |
| `/api/dataset` | GET | Get current dataset info |
| `/api/preview` | POST | Preview CSV without processing |
| `/api/upload` | POST | Upload and process CSV |
| `/api/reset` | POST | Reset to default dataset |
