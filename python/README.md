# Python Scripts

This folder contains Python scripts for data analysis and visualization.

Scripts are numbered in order of execution:

1. `01_data_cleaning.py` - Clean and prepare the dataset
2. `02_sql_analysis.py` - Connect to SQLite and run queries
3. `03_eda.py` - Exploratory Data Analysis
4. `04_matplotlib_viz.py` - Charts using Matplotlib
5. `05_seaborn_viz.py` - Charts using Seaborn
